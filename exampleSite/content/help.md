description: "Linewise commands and keyboard navigation."
---

Linewise keeps navigation close to Vim's muscle memory.

| Key        | Action               |
| ---------- | -------------------- |
| `j` / `k`  | Move selection       |
| `Enter`    | Open selected item   |
| `gg` / `G` | First or last item   |
| `/`        | Open search palette  |
| `:`        | Command mode         |
| `b`        | Buffer list          |
| `Ctrl+d/u` | Scroll half page     |
| `Ctrl+b`   | Scroll page up       |
| `q`        | Quit current context |
| `Esc`      | Normal mode          |

Browser page search stays on `Ctrl+f`.
